# life-web

หน้าแสดงแผนประจำวันของระบบผู้ช่วยส่วนตัว — หน้าเดียว ไม่มี dependency ไม่มี build step

**repo นี้ public โดยตั้งใจ และต้องไม่มีข้อมูลส่วนตัวอยู่เลย** ข้อมูลทั้งหมด (ตารางชีวิต · งาน · โน้ต)
อยู่ใน repo ส่วนตัวคนละอัน หน้านี้ดึงผ่าน GitHub API ด้วยโทเคนที่ผู้ใช้กรอกเองในเบราว์เซอร์

- ไม่มีโทเคนฝังในโค้ด — ผู้ใช้กรอกเองทุกครั้ง
- ไม่ติ๊ก "จำไว้ในเครื่องนี้" → เก็บใน `sessionStorage` หายเมื่อปิดแท็บ (ใช้บนเครื่องที่ไม่ใช่ของเรา)
- ติ๊ก → `localStorage` (เครื่องส่วนตัวเท่านั้น)
- โหลดไม่ได้จะบอกสาเหตุตรง ๆ ไม่แสดงข้อมูลเก่าค้างไว้เงียบ ๆ
- ข้อมูลเก่ากว่า 18 ชม. จะขึ้นเตือนว่า workflow ฝั่ง repo ส่วนตัวอาจไม่ได้รัน

## โทเคนที่ต้องใช้

Fine-grained personal access token · เลือกเฉพาะ repo ส่วนตัวอันเดียว · สิทธิ์ **Contents: Read-only**
อายุไม่เกิน 90 วัน
