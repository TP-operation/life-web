# life-web

หน้าแสดงแผนประจำวันของระบบผู้ช่วยส่วนตัว — หน้าเดียว ไม่มี dependency ไม่มี build step

**repo นี้ public โดยตั้งใจ และต้องไม่มีข้อมูลส่วนตัวอยู่เลย** ข้อมูลทั้งหมด (ตารางชีวิต · งาน · โน้ต)
อยู่ใน repo ส่วนตัวคนละอัน หน้านี้ดึงผ่าน GitHub API ด้วยโทเคนที่ผู้ใช้กรอกเองในเบราว์เซอร์

| กฎ | มีกลไกบังคับไหม |
|---|---|
| ไม่มีโทเคนฝังในโค้ด — ผู้ใช้กรอกเองทุกครั้ง | ✅ `secretsIn()` แดงถ้าเจอรูปของโทเคนในไฟล์ |
| ไม่ติ๊ก "จำไว้ในเครื่องนี้" → `sessionStorage` หายเมื่อปิดแท็บ | ✅ `tokenWrite()` อ่าน**บรรทัดที่เขียนโทเคนจริง** และเทสกลายพันธุ์ `index.html` ตัวจริง |
| ติ๊ก → `localStorage` (เครื่องส่วนตัวเท่านั้น) | ✅ อันเดียวกัน |
| ข้อมูลเก่ากว่า 18 ชม. ขึ้นเตือน | ⚠️ `staleHours()` ยันว่ากฎยังอยู่ **และเกณฑ์ไม่หลวมเกิน 18** · แต่ยันไม่ได้ว่ามันขึ้นจริงบนหน้าจอ |
| โหลดไม่ได้บอกสาเหตุตรง ๆ ไม่แสดงข้อมูลเก่าค้างเงียบ ๆ | ❌ **ยังอาศัยคน** ต้องรันหน้าใน DOM ถึงจะตรวจได้ |

> [!warning] สองข้อล่างยังไม่ถูกบังคับเต็มที่ — **อย่าอ่านตารางนี้ว่าปลอดภัยครบ**
> 8 ก.ย. 2026 การตรวจพบว่าทั้งห้าข้อ **ไม่มีข้อไหนถูกบังคับเลย** ทั้งที่เขียนไว้ราวกับเป็นข้อกำหนด
> ลบเงื่อนไข 18 ชม. ทิ้ง หรือบังคับให้โทเคนลง `localStorage` เสมอ — ด่านผ่านเงียบทั้งคู่
>
> **ข้อกำหนดที่ไม่มีกลไกบังคับ คือข้อที่ยังไม่เสร็จ** ไม่ว่าเอกสารจะเขียนว่าอย่างไร
