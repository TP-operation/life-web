# portraits

รูปตัวละครของ agent — ชื่อไฟล์ต้องตรงกับ `portrait:` ใน `70-agents/*.md` ของ repo `life`

```
portraits/
  iris.jpg  ada.jpg  ray.jpg  wren.jpg  cora.jpg  scout.jpg  mason.jpg  vera.jpg   ← รูปการ์ด 1:1
  scene/
    iris.jpg  ada.jpg  …                                                           ← ภาพมีพื้นหลัง 3:2
```

**รูปการ์ด** — จัตุรัส 256×256 แสดงจริงที่ 44px · ครอปจากภาพมีพื้นหลังได้
**ภาพมีพื้นหลัง** — อยู่ใน `scene/` ชื่อไฟล์เดียวกัน · 1200 ด้านยาว · ยังไม่ได้ใช้บนหน้าเว็บ

## ได้รูปใหม่มาทำยังไง

1. วางภาพมีพื้นหลังไว้ที่ `scene/<ชื่อตัวพิมพ์เล็ก>.png` หรือ `.jpg`
2. เปิด `make-cards.py` เติมกรอบครอปของตัวนั้นใน `CROPS` — **เป็นสัดส่วน 0–1 ไม่ใช่พิกเซล**
3. `python portraits/make-cards.py` — ย่อภาพพื้นหลัง แปลงเป็น jpg และครอปรูปการ์ดให้

ตัวไหนยังไม่ได้เติมกรอบ สคริปต์จะบอกว่า *"มีภาพแล้วแต่ยังไม่ได้วัดกรอบครอป"* แล้วข้ามไป
Pillow เป็นของเครื่องมือนี้เท่านั้น **หน้าเว็บยังไม่มี dependency อะไรเหมือนเดิม**

> ⚠️ **ภาพมีพื้นหลังต้องอยู่ใน `scene/` เท่านั้น ห้ามวางไว้ข้าง ๆ รูปการ์ด**
>
> Windows มองชื่อไฟล์แบบไม่แยกตัวพิมพ์ใหญ่เล็ก — **`Iris.jpg` กับ `iris.jpg` คือไฟล์เดียวกัน**
> สคริปต์ที่ครอป `Iris.jpg` ออกมาเป็น `iris.jpg` จึงเขียนทับต้นฉบับตัวเอง **โดยไม่มีอะไรเตือน**
> (เกิดขึ้นจริงแล้วครั้งหนึ่ง เสียต้นฉบับไปสามใบ) · คนละโฟลเดอร์ = ชนกันไม่ได้อีก

> ⚠️ **ย่อให้ใต้ 200 KB ต่อไฟล์** — repo นี้เป็น GitHub Pages ที่โหลดทุกครั้งที่เปิดหน้า
> และหน้านี้ต้องเปิดจากคอมที่ทำงานซึ่งเน็ตไม่ได้เร็ว · `.jpg` เล็กกว่า `.png` หลายเท่าสำหรับภาพแบบนี้

ไม่มีไฟล์ก็ไม่พัง — การ์ดจะขึ้นตัวอักษรแรกของชื่อแทน (`V` สำหรับ Vera)
