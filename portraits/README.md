# portraits

รูปตัวละครของ agent — ชื่อไฟล์ต้องตรงกับ `portrait:` ใน `70-agents/*.md` ของ repo `life`

```
iris.png  ada.png  ray.png  wren.png  cora.png  scout.png  mason.png  vera.png
```

**รูปการ์ด** — สี่เหลี่ยมจัตุรัส 256×256 ก็พอ แสดงจริงที่ 30px
**ภาพมีพื้นหลัง** — ลงท้าย `-scene.png` สำหรับหน้าทะเบียน ยังไม่ได้ใช้บนหน้าเว็บ

> ⚠️ **ย่อให้ใต้ 200 KB ต่อไฟล์** — repo นี้เป็น GitHub Pages ที่โหลดทุกครั้งที่เปิดหน้า
> และหน้านี้ต้องเปิดจากคอมที่ทำงานซึ่งเน็ตไม่ได้เร็ว

ไม่มีไฟล์ก็ไม่พัง — การ์ดจะขึ้นตัวอักษรแรกของชื่อแทน (`V` สำหรับ Vera)
